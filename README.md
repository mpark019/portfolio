# mjpark.dev portfolio

- Framework: [Next.js](https://nextjs.org/)
- Deployment: [Vercel](https://vercel.com/)
- Styling: [Tailwind CSS](https://tailwindcss.com/)

## Overview

- `src/components/*` - Shared components used across the site, including the header, Cybertronian cursor.
- `src/app/*` - App Router pages, the root layout, global styles, and site icon.
- `src/app/gaming/*` - Interactive gaming page with a custom retro video player.
- `src/app/projects/page.tsx` - Projects listing at `/projects`.
- `public/*` - Static assets, including the resume, Cybertronian font, project photos, and videos.
- `next.config.ts` - Next.js configuration with React Compiler enabled.

## Running Locally

This application is currently using Node version: `26.7.0`

```sh
npm install
npm run dev
```
