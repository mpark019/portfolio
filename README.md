# mjpark.dev portfolio

---

- Framework: [Next.js](https://nextjs.org/) 16
- Deployment: [Vercel](https://vercel.com/)
- Styling: [Tailwind CSS](https://tailwindcss.com/) 4

## Overview

---

- `src/components/*` - Shared components used across the site, including the header and text-reveal animation.
- `src/app/*` - App Router pages, the root layout, global styles, and site icon.
- `src/app/gaming/*` - Interactive gaming page with a custom retro video player.
- `public/*` - Static assets, including resume, cybertronian font, and parkour video.
- `next.config.ts` - Next.js configuration with React Compiler enabled.

## Running Locally

---

This application is currently using Node version: `26.7.0`

```sh
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
